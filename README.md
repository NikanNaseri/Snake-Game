# Retro Snake Game 🐍✨

A classic **Snake** game implemented in Python using the **Pygame** library, packed with modern gameplay twists such as dynamic mystery boxes, temporary buffs, and an interactive textual menu system.

Designed with clean Object-Oriented principles and game loop management to deliver a smooth and engaging retro gaming experience!

---

## Features 🚀

- **Dynamic Mystery Boxes:** Spawns every 10 seconds, granting random temporary buffs for 5 seconds:
  - 🛡️ **Invincibility:** Pass through walls or self without dying.
  - ⚡ **Speed Boost:** Accelerate the snake for fast maneuvering.
  - ⭐ **Bonus Points:** Multiply your score gains.
- **Interactive Text Menu:** Start, pause (`P` key), and restart smoothly.
- **Score Tracking:** Keep track of your high scores and current progression.
- **Robust Game Loop:** Built on Pygame's event handling and frame-rate regulation.

---

## Requirements 📦

- Python 3.x
- Pygame library
